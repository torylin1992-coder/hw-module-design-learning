01 / Learning Path

六阶段学习路径：从器件到量产

不要按“教程章节”学硬件，按“板上真实存在的功能块”学。每个阶段都产出一个可以画进原理图的模块，学完就能拼出一块完整的板子。

01

电路与器件基础

欧姆定律之外的东西：电阻的功率与温漂、MLCC 的直流偏压特性、电感的饱和电流、MOSFET 的 Qg 与 Rds(on)、二极管的反向恢复。核心是学会读 datasheet 的绝对最大额定值和降额曲线。

产出器件选型表 · 降额规则
02

电源与上电时序

先画电源树，再画电路。LDO 与 Buck 的取舍、输入输出电容的取值、环路稳定性、软启动、PG 与使能级联、上下电时序、反接与过流保护。电源是整板故障率最高的模块。

产出电源树 · 上电时序图
03

数字最小系统

MCU 不启动是新手最常见的困局。供电去耦、晶振负载电容与走线、复位电路与 RC 常数、BOOT 引脚电平、SWD/JTAG 调试口、GPIO 复用与未用引脚处理——把最小系统做到一次上电成功。

产出最小系统原理图
04

模拟与信号链

从传感器到 ADC 的完整链路：分压/分流、运放的输入共模与轨到轨、单端与差分、抗混叠滤波、基准源精度、采样率与有效位数。目标是算清“我到底能测到多少位有效精度”。

产出误差预算表
05

接口与通信

UART、RS-485、CAN、I2C、SPI、USB、以太网。每个接口都要回答三件事：电平与端接、拓扑与地址、防护与隔离。总线跑不通，九成是端接、共地或时序余量的问题。

产出接口设计对照表
06

PCB、EMC 与可制造性

层叠与阻抗、地平面与回流路径、去耦电容的摆放、差分对与等长、ESD/浪涌泄放路径、热设计与铜箔面积、DFM 与测试点。这一步决定板子是“能跑”还是“能卖”。

02 / Knowledge Map

八个必须掌握的知识域

每个知识域都对应一组具体的检查项，而不是一句“要重视”。学完一个域，就去清单里勾掉对应条目。

A

电源完整性

电源树、纹波、环路、去耦网络、上下电时序与 PG 级联。

B

时钟与复位

晶振负载电容、起振余量、复位阈值、看门狗与掉电检测。

C

信号链与采样

分压/分流、运放配置、抗混叠滤波、基准与有效位计算。

D

接口与总线

电平标准、端接匹配、隔离、共模范围、地址与拓扑。

E

保护与可靠性

ESD、浪涌、反接、过流、过温、降额与失效模式分析。

F

PCB 与回流

层叠、参考平面、跨分割、过孔、阻抗与串扰控制。

G

EMC 与 EMI

辐射与传导路径、共模电流、滤波与屏蔽、预兼容测试。

H

可制造性

DFM 规则、测试点与治具、烧录与校准、BOM 与替代料。

05 / Method

三条让学习真正有效的建议

01

抄电路不如抄约束。看到一份参考设计，先问：输入电压范围多少？负载电流多大？环境温度多少？允许的纹波是多少？约束不同，同一个拓扑的取值完全不同。

02

先定验证方法，再画原理图。画之前就问自己：这个模块怎么证明它是对的？测哪个点、用什么仪器、合格判据是什么。答不出来说明还没设计清楚。

03

一个模块，一张评审清单。把踩过的坑固化进清单，下次画图时逐条对照。清单比记忆力可靠，也是团队里最有价值的资产。

06 / First Board

首板上电九步法

新板到手别急着插电。按顺序走，能省掉大量返修。

#动作判据
1目视 + 万用表测电源对地电阻无短路，阻值符合预期
2限流上电，先空载输入电流在静态范围
3逐轨测输出电压与纹波电压 ±3% 内，纹波达标
4测上电时序与 PG顺序正确，无反复抖动
5测复位与 BOOT 电平复位释放正常，BOOT 正确
6连调试器读 ID能识别芯片
7烧录点灯程序最小功能跑通
8逐模块加负载、测温度温升在降额范围内
9通信接口回环测试误码率、眼图达标
07 / FAQ

调试现场最常问的八个问题

完整版（含排查顺序与判据）在调试问答页。

上电后电源没有输出，第一个该测哪里？

先测使能脚（EN）电平，再测输入电压是否真的到了芯片引脚。八成的“没输出”是使能没拉高、输入被前级限流、或反馈分压虚焊。

电源纹波超标，怎么定位是开关噪声还是负载噪声？

空载与满载各测一次。空载仍大 → 环路或布局；满载才大 → 输入电容/电感不足或地弹。注意探头必须用弹簧地环，长地线本身会引入几十 mV 假纹波。

MCU 不启动，如何快速定位？

按“电—钟—复—口”顺序：供电是否全部到位、晶振是否起振、复位是否释放、调试口能否识别。任一步断掉就停在那里，不要跳步。

RS-485 通信偶发误码，先怀疑什么？

先看共地与共模电压，再看终端电阻是否只在两端、是否多余。长线两端不共地时的共模漂移是最常见的根因，隔离收发器往往比换线更有效。

ADC 读数一直在跳，是芯片坏了吗？

几乎不是。先看基准是否干净、采样保持电容驱动是否足够、模拟地与数字地是否在敏感处被大电流污染。用示波器看输入端真实波形，比看读数有用。

板子局部发热严重，怎么判断是否超规格？

用热像仪读器件表面温度，加上 datasheet 的 θJA 反推结温，再对照降额要求（一般结温不超过最大值的 80%）。别用“摸着烫”当判据。

辐射发射预测试超标，先改电路还是先改 PCB？

先定位频点归属哪个模块（关掉/旁路逐个验证），再决定。高频窄带通常是时钟或开关电源，宽带往往是接口线缆的共模电流——后者改共模电感与接地更有效。

参考设计能直接照抄吗？

拓扑可以抄，取值不能。器件参数由输入范围、负载、温度和成本共同决定。抄之前先把参考设计的约束条件还原出来，再判断是否覆盖你的场景。
