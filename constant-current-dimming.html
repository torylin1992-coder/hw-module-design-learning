恒流模拟调光电路设计教程

一份可直接照做的推导：PWM 怎么变成电流设定、两级 RC 的建立时间为什么是 57 ms 而不是 5τ，以及每个频率档位下 ARR 每走一步对应多少毫安。

Abstract

一页结论

这块板的核心是一条链路：PWM 占空比 → 滤波后的直流电压 → LED 电流。三个指标（建立时间、纹波、每步电流）全部由同一条链路决定，改一个电容就会同时动到另外两个。先把结论摆出来：

指标算式按本图参数
电流设定跨阻K = 1 / (G · R6)1 / (20 × 0.02 Ω) = 2.5 A/V
满量程（D = 100%）I = K · VPWM2.5 × 2.0 V = 5.00 A
满量程时 INA240 输出V = G · R6 · I5 A × 0.4 V/A = 2.0 V，距轨限 2.8 V 余量 0.8 V（40%）
调光分辨率N = fCLK / fPWM，bit = log2N4800 步 = 12.23 bit（完整覆盖 0~5 A）
每步电流ΔI = IFS / N5.00 A / 4800 = 1.04 mA
滤波时间常数τ = R · C3.74 kΩ × 2.2 µF = 8.23 ms
建立时间（1%）t1% = 6.64 τ（两级同参数 RC）54.6 ms，实测 57 ms

最容易错的一步：拿单级指数 5τ 去估两级 RC 的建立时间。单级 5τ 是 41 ms，两级要到 1% 需要 6.64τ，差 33%。同样，纹波也不能只算一级衰减——两级是平方关系，差一个数量级。

下面按「电路怎么接 → 环路怎么闭合 → 建立时间怎么算 → 纹波怎么算 → 频率步进怎么换算成电流」的顺序展开。所有公式都能用页面末尾的在线计算器复算。

1.1 信号是怎么走的

把三条路径分开看，电路就不难了：

  • 01
    设定路径PWM_LED（10 kHz，0~100%）→ R5 → C4 → R4 → C3 → 运放反相端 V−。占空比被滤成直流电压。
  • 02
    反馈路径LED 电流流过 R6 → INA240A1 放大 20 倍 → R3/C12 低通 → 运放同相端 V+。
  • 03
    执行路径运放输出 VOA → R9 866 kΩ → FB 节点（0.6 V 基准）→ 芯片调整占空比 → VOUT → LED 电流。

1.2 为什么采样电阻放在 LED 回路里

R6 串在 LED 电流的实际路径上，INA240 测的是它的压降。这样电流环直接闭合在负载电流上，而不是电感电流或输出电压上，LED 的 Vf 漂移、线束电阻、温度变化都被环路吃掉，只剩采样电阻的容差和放大器误差留在精度里。

代价是 R6 上有持续功耗：5 A 时 P = I²R = 5² × 0.02 = 0.5 W。1206 封装额定 1 W，恰好用 50%，符合常规降额，但要注意焊盘散热铜箔是否够——大电流下这个电阻是板上最热的无源器件之一。

Chapter 02

第 2 章 环路怎么闭合

三个公式串起来，就是整条调光链的静态关系。

2.1 采样链：电流变成电压

VINA = G · R6 · ILED = 20 × 0.02 Ω × ILED = 0.4 V/A × ILED
G = 20（INA240A1），R6 = 0.02 Ω → 0.4 V/A。PWM 幅度 2.0 V，D = 100% 时设定电压 2.0 V 正好对应满量程 5 A，此时 INA240 输出也是 2.0 V——供电 3.0 V、轨限约 2.8 V，余量 0.8 V（40%），采样链不撞轨；硬件理论极限 2.8 V / 0.4 V/A = 7.0 A，占空比全程 0~100% 线性可用，不需要软件限占空比。

2.2 设定链：占空比变成电压

VDIM = D · VPWM
D 为占空比（0~1）。10 kHz 下两级 RC 的残余纹波只有几十 µV，直流分量就是这个平均值。

2.3 虚短把两条链锁在一起

运放工作在闭环，反相端与同相端电位相等（V− = V+），而两端各接一条链的直流输出，于是：

D · VPWM = G · R6 · ILED
⇒ ILED = D · VPWM / (G · R6) = K · D · VPWM，K = 2.5 A/V

这就是全部：电流与占空比严格成正比，比例系数只由 VPWM、G、R6 三个量决定。调光线性度好不好，就看这三个量稳不稳。

这一版参数为什么舒服：三个量互相咬合。PWM 幅度 2.0 V × 跨阻 2.5 A/V = 满量程正好 5 A；5 A 时 INA240 输出 2.0 V，距 2.8 V 轨限余量 40%；占空比 0~100% 全程线性对应 0~5 A，不需要软件限 Dmax，4800 步全部有效。唯一要盯住的是 PWM 信号源的幅度：满量程 = K · VPWM，若日后把 PWM 换成 3.0 V 或 3.3 V 域的信号直出，满量程会变成 7.5 A / 8.25 A，超出 buck 的 6 A 能力——换信号源或加电平转换时必须同步复核这个乘积。

2.4 运放怎么改变输出电压

FB 是 0.6 V 基准点。R8 与 R10 分压设定输出电压，R9 把运放输出接进来，相当于往分压中点注入电流。对 FB 节点列 KCL（忽略 FB 引脚电流）：

(VOUT − 0.6)/R8 + (0 − 0.6)/R10 + (VOA − 0.6)/R9 = 0
⇒ VOUT = 0.6 · (1 + R8/R10 + R8/R9) − VOA · (R8/R9)
代入 R8 = 432 kΩ，R10 = 100 kΩ，R9 = 866 kΩ：
VOUT = 3.49 V − 0.499 · VOA
VOA 从 0 升到 2.0 V（3.0 V 供电只用到 2/3 行程），VOUT 从 3.49 V 降到 2.49 V。运放输出越高，输出电压越低——这是负反馈成立的关键。若 LED 串压降低于 2.5 V 导致调不下去，可把 OPA330 换到 3.3 V 供电，VOUT 最低到 1.84 V。注意 3.49 V 这个上限本身就由 FB 分压上限电阻决定，是环路的"指令天花板"——本电路实测就是被它卡住 5 A 的，详见 7.3。

2.5 极性检查（这一步不能省）

假设扰动让 LED 电流升高一点，沿着环路走一圈，看它会不会被压回去：

  • 01
    ILED ↑ → R6 压降 ↑ → INA240 输出 ↑（V+ 升）
  • 02
    VOA ↑ → 经 R9 注入 FB 的电流增加 → FB 节点电位 ↑
  • 03
    VOUT ↓ → LED 压差减小 → ILED ↓（回到原值）

三个箭头方向合起来是负号，环路稳定。若把运放的两个输入接反，就会变成正反馈，一上电就顶到最大电流——调试时先测这一点，比看波形快。

Chapter 03

第 3 章 建立时间怎么算

调光指令从"改占空比"到"电流到位"，中间要穿过两级 RC。建立时间就是这两级电容充到目标值的时间。

3.1 时间常数

τ = R4 · C4 = R5 · C3 = 3.74 kΩ × 2.2 µF = 8.23 ms
两级参数故意取成相同值，这样响应形状最好算。

3.2 单级容易，两级要解方程

单级 RC 的阶跃响应是 1 − e−t/τ，5τ 到 99.3%。但这里是两级串联，前一级的输出就是后一级的输入，阶跃响应变成：

v(t) = 1 − (1 + t/τ) · e−t/τ
两级同参数 RC、级间有隔离（运放输入不取电流）时的标准解。注意那个多出来的 (1 + t/τ) 因子，它让曲线尾部拖得更长。

令误差 (1 + x)e−x = ε，解出 x，再乘 τ：

判据x（τ 的倍数）t（τ = 8.23 ms）用途
到 90%3.8932.0 ms粗略响应时间
到 99%（1%）6.6454.6 ms最常用的"建立完成"判据
到 99.9%（0.1%）9.2376.0 ms高精度测量、暗场切换
到 99.99%11.7696.7 ms—

实测 57 ms 落在 1% 判据附近（对应 x = 6.93，误差约 0.73%），说明环路本身（运放压摆、buck 的几十 µs 响应）不是瓶颈，主导项就是这两颗 2.2 µF。

3.3 想更快，代价是什么

τ 与 C 成正比，建立时间同比例缩短；但纹波与 C² 成反比，砍一半电容，纹波涨 4 倍。这是一条硬约束：

Chapter 04

第 4 章 纹波怎么算

这块电路里有两个完全不同的纹波，容易被混为一谈：一个是 PWM 滤波残余（影响平均电流的抖动），一个是 buck 开关纹波（影响瞬时电流波形）。前者决定调光精度，后者决定光输出纹波和 EMI。

4.1 PWM 残余纹波：从方波到微伏

PWM 是方波，先拆成傅里叶级数，再用两级 RC 的幅频特性逐次衰减：

vPWM(t) = D·VPWM + (2VPWM/π) · Σn=1,3,5… sin(nπD)/n · sin(2πnft)
基波幅度 A1 = (2VPWM/π) · sin(πD)，在 D = 50% 时最大，等于 2VPWM/π
单级 RC 衰减 |H(f)| = 1/√(1 + (2πfτ)²) ≈ 1/(2πfτ)（当 f ≫ 1/2πτ）
两级串联：|H|² ，且第 n 次谐波再额外除以 n

因为 (2πfτ) 在 10 kHz 时等于 517，远大于 1，可以用近似式。把各次谐波按最坏情况线性叠加（Σ1/n² = 1.234）：

Vpp ≈ 2 · A1 · |H|² · 1.234 = 2 × 1.27 V × (1/517)² × 1.234
Vpp ≈ 11.7 µV（D = 50%，VPWM = 2.0 V）
RMS 约 3.9 µV。若按基波单独算（不加谐波）为 9.5 µVpp。
i

注意 D 的影响：D 越接近 0 或 100%，sin(πD) 越小，纹波越低；D = 50% 是最坏点。所以测纹波要在 50% 占空比下测，在 1% 或 99% 测出来的数会好看得没有意义。

4.2 折算成电流：这一步才看得出好坏

ΔIripple = Vpp / (G·R6) = 11.7 µV / 0.4 V/A = 29.4 µA
相对满量程：29.4 µA / 5 A = 0.00059%，约 1/35 LSB

结论：按这颗 2.2 µF，调光设定纹波远小于一步电流（1.04 mA），分辨率不会被纹波吃掉。这也是 12.23 bit 这个标称值能站得住的前提。

4.3 buck 开关纹波：另一个量级

功率级是 2.4 MHz 同步 buck，电感 0.47 µH，输出 3.19 V / 输入 4.2 V：

D = VOUT/VIN = 3.19/4.2 = 0.76
ΔIL = VOUT(1 − D)/(L·fSW) = 3.19 × 0.24/(0.47 µH × 2.4 MHz) = 0.68 A
ΔVOUT ≈ ΔIL/(8·C·fSW) = 0.68/(8 × 44 µF × 2.4 MHz) = 0.8 mV

这 0.68 A 的三角波纹波会直接出现在 LED 电流上（电流环带宽只有几十 Hz，压不住 2.4 MHz）。它折算到采样端是 0.68 × 0.02 = 13.6 mV，被 INA240 放大后 272 mV，再经 R3/C12（fc = 10.6 kHz）衰减约 226 倍，到运放输入端约 1.2 mV——所以 R3/C12 是必须的，没有它运放会一直"看见"开关噪声。

Chapter 05

第 5 章 频率步进与电流精度

这是最容易被含糊过去的一节。「精度」其实由两个独立的量决定，混在一起谈就会得出错误结论。先把三个概念分开：

概念定义由什么决定本图数值
分辨率能区分的最小占空比变化定时器计数 N = fCLK/fPWM4800 步 = 12.23 bit
步进电流 ΔI每走 1 个计数，LED 电流变化多少IFS/N1.04 mA
有效精度分辨率与纹波中较差的那个ΔI 与 ΔIripple 合成见下表

5.1 频率一变，分辨率跟着变

定时器时钟固定时，PWM 频率与 ARR 是倒数关系。频率越高，一个周期内的计数越少，分辨率越低：

N = fCLK / (fPWM · (PSC + 1))　（本图取 PSC = 0，fCLK = 48 MHz）
bit = log2 N　　ΔD = 1/N　　ΔI = IFS/N（IFS = K·VPWM 为 D = 100% 满量程）
10 kHz → N = 4800 → 212.23 ≈ 4800，这就是标注「12.23 bit」的来历。

5.2 频率一变，纹波也跟着变

但方向相反：频率越高，RC 对基波的衰减越大，残余纹波越小（纹波 ∝ 1/f²）。于是出现一对反向的力：

ΔI（分辨率项） ∝ 1/N ∝ fPWM　　← 频率越高越差
ΔIripple（纹波项） ∝ 1/fPWM²　← 频率越高越好
综合 ≈ √(ΔI² + ΔIripple²)

5.4 最优点在哪

把两条曲线画在同一张图上，交点大约在 5 kHz：此处分辨率 13.23 bit，纹波压到 0.12 mA（远小于一步 0.52 mA），综合精度 0.53 mA 是六档里最好的。10 kHz 用 1.04 mA 换来了更低纹波和两倍于听觉上限的刷新率，是更常见的选择。

  • 要精度优先：5 kHz，13.23 bit / 0.53 mA，前提是 5 kHz 不会与摄像头帧率或电源环路打架。
  • 要响应和低纹波：10~20 kHz，12.23~11.23 bit，1.0~2.1 mA。
  • 要绝对避免可见闪烁：>20 kHz，但要接受 11 bit 以下，且需要检查定时器时钟是否够高（N 太小会让 ΔI 上升很快）。

5.5 选频率的四步

  • 01
    定精度需求先把可接受的最小电流步进写下来（例如 2 mA），用满量程 IFS（本例 5 A）除以它得到需要的 N。
  • 02
    反推频率上限fPWM ≤ fCLK/N。本例每步 1.04 mA（K = 2.5 A/V、fCLK = 48 MHz）：要 2 mA 步进，N ≥ 2500，频率不超过 19.2 kHz；要 1 mA 步进，N ≥ 5000，上限 9.6 kHz。
  • 03
    校核纹波用 4.1 的公式算这个频率下的纹波，确认折算电流小于 1 LSB；不满足就加大 C3/C4。
  • 04
    校核建立时间6.64τ 必须小于系统的调光刷新周期，否则上一档还没稳就切下一档，画面会"糊"。
!

一个常被忽略的约束：建立时间 54.6 ms 意味着调光指令最快只能 18 次/秒。如果上层以 60 Hz 或 120 Hz 刷新亮度，实际电流会一直追不上设定值，表现为亮度"发闷"、暗场切换有拖影。这种情况必须减小 C（并接受纹波上升），或改用"PWM 直接斩波 + 恒流源"的方案。

Chapter 07

第 7 章 误差预算与降额

分辨率是"能分多细"，精度是"准不准"。12.23 bit 的分辨率配上 1% 的采样电阻，实际精度就只有 7 bit 左右——这一步必须单独算。

误差源典型值折算电流误差占满量程
R6 容差1%（1206 厚膜）±50 mA1.0%（主导项）
INA240A1 增益误差±0.2%（25 °C）±10 mA0.2%
INA240 失调±25 µV（RTI）±1.25 mA0.025%
OPA330 失调±25 µV±62.5 µA0.00125%
FB 基准误差±1%影响 VOUT，被电流环抑制≈0
R8/R10/R9 容差1%影响调节范围，被环路抑制≈0
RSS 合计（√Σe²）—±51 mA≈1.0%
i

RSS 是什么意思：Root Sum Square，平方和开根号。这四项如果按最坏情况直接相加，是 1.0 + 0.2 + 0.025 + 0.001 = 1.23%（61.3 mA）；但四项同时各自顶到极限的概率极低，按独立随机量合成，总标准差 = √(50² + 10² + 1.25² + 0.06²) = 51.0 mA（1.02%）。工程惯例：RSS 估典型批量，线性相加估最坏单台。

用 RSS 有两个前提：① 各误差相互独立（不同器件、不同机理）；② 方向随机（正负各半）。像 R6 的 1% 对单块板其实是一个固定的增益偏差，不会因为"随机"而互相抵消——同一块板的上限就是 R6 那 1%，这也是为什么下面说"软件单点校准"比换电阻更划算：校准把这项系统性偏差直接消掉，剩下的随机项才轮到 RSS 说话。

结论很明确：精度卡在 R6 上。换成 0.1% 的合金电阻（或 4 线接法的 Kelvin 采样），总误差能压到 0.25% 以内；不换的话，软件里做一次单点校准也能把 1% 的增益误差消掉。

唯一要盯住的是 PWM 信号源的幅度。满量程 = K · VPWM，现在 2.0 V 对应 5 A；若日后 PWM 换成 3.0 V 或 3.3 V 域直出，满量程会变成 7.5 A / 8.25 A，超出 TPS6286A06 的 6 A 能力，100% 时 R6 功耗和 INA240 轨限也都要重核。换 MCU、改电平或动信号链时，先复核这个乘积。

7.2 输入电压余量（dropout）校核——实测踩过的坑

恒流环再强，也只能指挥 buck 在"它给得出来的电压"范围内工作。buck 只能降压，输出上限也不是理想公式 D×VIN，而是要扣掉电流路径上所有电阻的压降：

VOUT,max = VIN − I × (RDS(on)·HS + DCRL1 + RPCB)

实测案例：VIN = 3.6 V 时命令满量程，电流顶在 4 A、VOUT 卡在 3.4 V——反推路径电阻 ≈ (3.6 − 3.4)/4 = 50 mΩ（高侧管导通电阻 + 电感 DCR + PCB 走线，量级合理）。5 A 时可用电压只剩 3.6 − 5×0.05 ≈ 3.35 V，而 LED 走 5 A 需要 Vf(5 A) + 0.1 V ≈ 3.55 V（按 LED 动态电阻 0.1~0.15 Ω 估算），差约 0.2 V，电流就停在 LED I-V 曲线与可用电压的交点上。LED 的 di/dV 很陡，0.2 V 的电压缺口就是 1 A 的电流差。这不是环路故障——FB 此时始终低于 0.6 V 基准，buck 已维持最大导通，环路"还想再推"但功率级给不出来。电池放电末端（3.2 V）会更严重：可用电压 3.0 V 左右，电流可能只剩 2~3 A。满量程 5 A 本质上只在电池高电量区间可达，这是 buck 拓扑"只能降压"的固有属性。

7.3 实测根因复盘：压死的其实是"指令上限"，不是纹波

上面这个 4 A 卡死现象后来实测定案：把 FB 网络的输出电压范围从 2~3.5 V 改成 2~3.8 V，5 A 立刻可达。这说明主要短板不在功率侧的路径压降，而在控制侧——环路能给 VOUT 的"指令上限"只有 3.49 V。回忆 2.4 节的注入方程 VOUT = 3.49 − 0.499·VOA：当运放把 VOA 压到 0 V（"我要更高电压"的极限状态）时，VOUT 就到顶 3.49 V，再多一分都给不出。而 5 A 需要 ≈3.55~3.6 V，差这 0.1~0.2 V，电流就停在 4 A。

这个案例里其实叠着两层限制，谁先撞上谁生效：① 控制侧——FB 网络/注入方程给定的 VOUT 指令上限（3.49 V）；② 功率侧——输入电压减去路径压降后的物理上限（3.6 V 输入、50 mΩ 路径下 5 A 时约 3.35 V）。本次修复把①抬到 3.8 V 后环路立刻找到平衡点，但②仍在——电池电压往下掉的时候，限制会切换到②，到时候电流又会到不了 5 A。所以 7.2 的 dropout 校核仍然必须做，控制侧余量调大只是把"墙"往后推了一段。

!

抬指令上限之后要跟着复核三处：① 范围下限——若只抬分压上限电阻，斜率不变，新范围是 3.8 − 0.499×2.0 = 2.8 V 起（原来 2.49 V 起），最低亮度所需的 LED 电压必须仍低于 2.8 V 才调得下去；② TPS6286A06 数据手册允许的 VOUT 最大规格是否覆盖 3.8 V；③ 输入电流——5 A × 3.55 V ≈ 17.8 W，折到 3.6 V 输入端约 5.2 A，离 6 A 额定只剩 13% 余量。

→

为什么可以排除"纹波太大"：调光设定端纹波实测 11.7 µVpp（4.1 节），折算电流 29 µA——与 1 A 的电流缺口相差五个数量级，机理上够不着。故障特征也完全不同：纹波问题表现为输出抖动、闪烁、示波器上电流来回晃；而"稳稳卡在 4 A 不动"是典型的饱和/限幅特征——运放输出贴死一端的轨（本例贴 0 V）、或 FB 网络到顶。排查这类问题的第一动作：测 VOA，看它是不是贴轨了。

→

校核条件写进设计规则：VIN,min ≥ Vf(Imax) + Imax × (R6 + RDS(on) + DCR + RPCB)，并留 0.3~0.5 V 余量。达不到时的解法：① 按最低电池电压下的可达电流定义满量程并逐点标定；② 压低路径电阻（加粗走线、选低 DCR 电感、必要时两颗电感并联）；③ 换 buck-boost 或提高 VIN。固件建议检测"命令满量程但电流到不了"的状态并上报，否则用户端表现为最大亮度随电量漂移。

Chapter 09

第 9 章 常见问题

9.1 为什么不用 PWM 直接斩波 LED，而要走模拟调光？

直接斩波效率高、分辨率只受定时器限制，但有两个问题：一是开关沿的 di/dt 会带来 EMI 和振铃，二是低亮度时窄脉冲会让 LED 的色坐标偏移（不同电流下光谱不同）。模拟调光让电流连续，光谱稳定、无频闪，代价就是这里讨论的建立时间与纹波。

9.2 建立时间实测比 54.6 ms 大很多，差在哪？

按可能性排序：① C3/C4 是 X5R/X7R 大容差（±20%），实际容量偏大；② 运放从饱和恢复时的压摆率限制（OPA330 约 0.16 V/µs，2 V 摆幅约 13 µs，一般不是主因）；③ buck 在轻载进入 PFM，输出阻抗变高。先测运放输出波形，看是不是被压摆率拖住。

9.3 为什么纹波测出来比算的大？

先看是不是在 D = 50% 测的（最坏点）。其次检查探头：普通鳄鱼夹地线会引入几十 mV 的开关噪声，把 µV 级信号完全淹没。第三，PWM 源的上升沿如果不陡（比如经过光耦或长线），高频分量减少，纹波反而会小；反之如果 MCU 直出，边沿很陡，高次谐波会多算一些。

9.4 想同时要快和准，有什么办法？

三条路：① 把 C3/C4 减小到刚好让纹波 < 1 LSB（本例 470 nF 时仍有 12.23 bit，建立时间 11.7 ms）；② 提高 PWM 频率并加大 C，让纹波和建立时间同时改善，但分辨率会下降；③ 换 16 bit DAC 直接给设定电压，彻底绕开 RC 与分辨率问题——成本换性能，是最干脆的方案。

9.5 这套算法能用在别的恒流电路上吗？

能。第 2 章的 K = 1/(G·R6) 与第 3、4 章的 RC 结论与具体芯片无关，只要满足两个条件：设定端是"电压→电流"的线性关系，滤波是 RC 低通。换成运放 + 线性 MOS 的恒流源、或者带模拟调光引脚的 LED 驱动 IC，公式照用。

9.6 命令 20% 电流只有 0.833 A（应为 1 A），差在哪？

实测案例：负载 2.9 V、输入 4 V，命令 20% 期望 1.0 A，实测 0.833 A。先用排除法定位：这个工况下环路不可能饱和——只需 VOUT ≈ 2.92 V，距指令上限 3.8 V 和输入 4 V 都有巨大余量，运放行程也在中间。所以环路必然处于平衡态，而平衡时 VDIM = INA 输出 = 0.833 × 0.4 = 0.333 V。也就是说电流环毫无问题，它精确复现了指令；错的是指令本身——0.4 V 只送到了 0.333 V，丢了 16.7%。这不是"精度差"，是"指令错"。

两步定位（一只万用表就够）：① 测运放两个输入端。若 V+ = V− ≈ 0.333 V → 设定链路丢电压（往下看情况 A）；若 V+ = V− ≈ 0.400 V 但电流仍是 0.833 A → INA240 内部有 +67 mV 偏置，最可疑的是 REF 引脚（查它是直接接地还是接了分压，情况 D）。② 再扫几个占空比画曲线，误差形态直接指向根因：

误差形态特征根因方向
比例型（各点都 ×0.833）50% → 2.08 A，100% → 4.17 AA3 滤波器输出被额外电阻负载分压（0.833 = RL/(RL+Rth)，Rth = 3.74 kΩ 时 RL ≈ 18.7 kΩ），或 PWM 幅度实测值与假设不符
低占空比才差100% 准、50% 略差、20% 差很多A1/A2：10 kHz 下 20% 只有 2 µs 脉宽，若前级有慢驱动（光耦、开漏弱上拉、额外 RC），窄脉冲摆不到位，滤波平均值 < D×V；100% 无边沿所以准——这是"满量程准、低占空比差"特征的标准解释
固定偏差（−0.167 A）20% → 0.833，50% → 2.33，100% → 4.83D：INA240 REF 引脚电位 +67 mV。回头看满量程那次是不是真的 5.00 A，还是 4.83 A 被当成"到 5 A 了"
精确的 1/60.833 = 5/6，分毫不差A3：实际占空比是 16.67% 而非 20%——固件映射、CCR/ARR 配置、亮度% 到占空比% 的换算出了岔子。用示波器直接量 PWM 引脚的真实占空比

顺带排除两项：负载只有 2.9 V 时 dropout 理论完全不适用（余量近 1 V）；输入电流 0.65 A 距 5 A 限流很远。教训与 7.3 一脉相承：电流环出问题先别怀疑环路，先测 VDIM 和 INA 输出这两个电压——平衡态下它们必须相等，这个等式一旦成立，问题就一定在环外。
